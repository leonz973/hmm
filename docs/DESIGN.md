# HMM 设计规范（UI/UX Design Spec）v1.0

> 依据 PRD v1.0 生成。风格基调：**清爽卡片风**（用户已确认）——浅色温暖底、白色圆角卡片、留白充足、家人易上手。移动端优先，桌面端自适应增强。

## 1. 设计原则

1. **家的温度**：低饱和绿为品牌主色（安心/稳定），琥珀橙做金额提醒色；不用冷冰冰的后台蓝。
2. **一眼看懂**：每屏一个主任务；金额用大号等宽数字；状态用颜色+图标双编码。
3. **录入优先**：主操作按钮常驻（移动端底部悬浮"+"），任何列表页 2 次点击内进入录入。
4. **全状态设计**：空态（引导录入）、加载态（骨架屏）、错误态（重试）、无网络态（离线只读提示）四态齐备。

## 2. 设计令牌（Design Tokens）

### 2.1 色彩（浅色为主，深色跟随系统）

| 令牌 | 浅色值 | 用途 |
| --- | --- | --- |
| `--color-primary` | `#059669` | 品牌主色：主按钮、选中态、进度条 |
| `--color-primary-weak` | `#ECFDF5` | 主色浅底：标签底、选中背景 |
| `--color-accent` | `#D97706` | 金额/账单预估/大额警告、CTA 强调 |
| `--color-accent-weak` | `#FEF3C7` | 提醒条浅底 |
| `--color-info` | `#0EA5E9` | 质保信息 |
| `--color-bg` | `#F6F8F5` | 页面背景（微绿灰，不用纯白刺眼） |
| `--color-card` | `#FFFFFF` | 卡片背景 |
| `--color-text` | `#0F172A` | 主文字（对比度 14.8:1） |
| `--color-text-2` | `#475569` | 次要文字（对比度 7.5:1） |
| `--color-text-3` | `#94A3B8` | 辅助/占位（仅用于 ≥14px 非关键信息） |
| `--color-border` | `#E5EAE6` | 分隔线/卡片描边 |
| `--color-danger` | `#DC2626` | 删除、已过期 |
| `--color-success` | `#059669` | 复用主色 |
| 深色模式 | 独立令牌集 | 背景 `#101614`、卡片 `#1A2420`、文字 `#E7ECE9`，深色下全部重新校验对比度 |

规则：金额涨跌、状态一律"颜色+文字/图标"双编码，不仅靠色觉区分；禁止在组件里硬编码 hex，一律用语义令牌。

### 2.2 字体

```
font-family: Inter, "MiSans", "PingFang SC", "HarmonyOS Sans SC",
             "Microsoft YaHei UI", "Noto Sans SC", sans-serif;
```

- 中文优先系统字体（免加载）；数字/拉丁用 Inter，金额数字启用 `font-variant-numeric: tabular-nums`。
- 字阶：标题 20/600 · 卡片标题 16/600 · 正文 14/400 · 辅助 12/400；金额大数字 28/700。
- 行高：正文 1.6；标题 1.3；内容高度由文字撑开，**禁止固定高度裁切文字**（无障碍：文本回流）。

### 2.3 圆角 / 阴影 / 间距 / 图标

- 圆角：卡片 16px · 按钮/输入框 10px · 标签 999px；禁纯灰实线边框，卡片用 `1px var(--color-border)` + 极浅阴影 `0 1px 3px rgba(15,23,42,.05)`。
- 间距刻度：4 / 8 / 16 / 24 / 32 / 48（Tailwind 默认刻度对齐）；屏宽 >768px 内容区最大 1200px 居中。
- 图标：**Phosphor Icons**（线性风格，统一 1.5px 描边，尺寸 16/20/24 三档）；**禁止 emoji 做结构图标**。
- 动效：微交互 150–250ms，缓动 `cubic-bezier(0.16,1,0.3,1)`；按压 scale 0.97；路由过渡淡入淡出 ≤250ms；尊重 `prefers-reduced-motion`。

### 2.4 触控与响应式

- 触摸目标 ≥44×44px；列表项整行可点；悬浮主按钮 56px。
- 断点：`<768px` 单列 + 底部 Tab 栏（首页/资产/日历/票据/我的）；`≥768px` 双栏网格；`≥1200px` 左侧边栏导航。
- 移动优先书写样式；表单在移动端单列，桌面端两列。

## 4. 关键界面规格

### 4.1 首页 Dashboard（第一屏定价值）

- 卡片顺序：待办提醒 → 本月概览 → 大额预警 → 30 天到期列表。
- 每张待办行：图标（按类型）+ 标题（"冰箱质保 11 月 30 日到期"）+ 副行（预估更换 ¥3,200）+ 右侧箭头。
- 大额预警卡：琥珀浅底 + 警示图标 + "3 个月后需换热水器，预估 ¥2,400 → 去规划"。

### 4.2 资产详情（信息最重的页面）

- 头部：照片/品类图标 + 名称 + 状态标签；"剩余寿命"进度条（主色→琥珀→危险三段变色）。
- 质保卡：多条质保并列，每条显示类型/起止/剩余天数徽标（>90 天绿、≤30 天琥珀、已过期灰红）。
- 凭证区：缩略图网格，点击全屏查看（支持双指缩放），可下载原件。
- 底部操作：编辑 · 记录更换（以旧换新向导）· 报废（二次确认）。

### 4.3 表单规范

- 行内校验：失焦即时校验，错误文案具体（"请输入 2024-01-01 之后的日期"），错误出现在字段下方 12px 危险色。
- 录入资产分 4 步，每步右上显示进度（1/4）；照片上传显示压缩进度与预览缩略图，可删除重传。
- 破坏性操作（报废/删除/移除成员/解散家庭）：按钮变红 + 输入确认或二次确认弹窗 + 后端软删除。

### 4.4 状态设计（全局要求）

| 状态 | 规格 |
| --- | --- |
| 空态 | 插画/图标 + 一句引导（"还没有资产，从冰箱开始记录吧"）+ 主行动按钮 |
| 加载态 | 骨架屏（卡片形状灰色呼吸），禁止转圈遮全屏 |
| 错误态 | 说明 + "重试"按钮；网络错误提示"当前离线，数据为最近缓存（只读）" |
| 并发冲突 | Toast："内容已被 {成员名} 更新，已为你刷新"；表单场景则顶部黄条提示重新编辑 |

## 5. 可用性与无障碍基线

- 对比度：正文 ≥4.5:1（深浅两套主题独立验证，不推断）；焦点环 2px 可见；键盘可达（Tab 顺序、Enter 提交、Esc 关弹窗）。
- 表单控件全部有 label；图标按钮带 `aria-label`；弹窗用语义 `role=dialog` + 焦点陷阱。
- 支持系统字体缩放（rem 布局）；`prefers-reduced-motion` 时禁用过渡动画。
- 安全区：移动端遵守刘海/手势条，底部 Tab 与悬浮按钮避开 safe-area。
